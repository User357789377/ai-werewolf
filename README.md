# AI 狼人杀

让 12 个不同厂商的 AI 大模型坐在一桌，玩一局 12 人**预女猎白**（屠边）网杀。
程序自动当法官：发牌、主持白天黑夜、计时、掐麦、统计票型，全程不用人管。
打完以后可以一键配音、生成手机网杀界面风格的竖屏视频，还能按某个玩家的视角剪成精华版。

- 每个 AI 只能看到自己身份该知道的信息（狼人知道队友，预言家知道查验结果……），独立思考、开麦发言、投票。
- 开局有 60 秒想打法；每次发言 90 秒思考 + 90 秒说话，超时被法官掐麦；投票等白天操作限时 60 秒，夜里狼人刀人 60 秒、预言家和女巫各 30 秒，超时按弃票 / 放弃处理。
- 前两晚死亡和白天被放逐的玩家有遗言；警长竞选、退水、警徽流、猎人开枪、白痴翻牌都有。

> 所有发言都由 AI 生成，不代表作者或任何厂商的观点。

## 安装

需要 Python 3.10 以上。

```
pip install -r requirements.txt
```

视频渲染要用中文字体：Windows（微软雅黑）、macOS（苹方）会自动找到；Linux 装 Noto Sans CJK，或者用 `--font 字体文件路径` 指定。

## 第一步：不花钱先跑通

```
python werewolf.py --mock
```

`--mock` 不调用任何接口，用随机发言走完一整局，用来确认流程和环境没问题。

## 第二步：填 API key、配 12 个座位

1. 把 `keys.example.txt` 复制一份，改名为 `keys.txt`，填上各家的 API key（**keys.txt 不要上传、不要发给别人**）。
2. `players.json` 里是 12 个座位，按顺序对应 1～12 号：名字、模型名、接口地址、用哪个 key、配音音色。默认都是各家官方的 OpenAI 兼容接口。
   - 模型名会随各家发布新版本变化，以官方文档为准。
   - 想换人，改对应那一行就行；头像按名字找 `assets/avatars/名字.png`，没有的话会用色块加首字。
3. 测试每个座位能不能调通（每个座位只发一句话，花费很少）：

```
python werewolf.py --config players.json --check
```

只想先用一个 key 低成本试试：`players_test.json` 把 12 个座位都换成了智谱的同一个模型。

## 第三步：打一局

```
python werewolf.py --config players.json
```

对局记录保存在 `out/时间/` 下：`log.json`（完整记录，给配音和剪辑用）、`script.md`（上帝视角的可读剧本）。每打完一天自动存一次盘，中途断了已打完的部分也不会丢。

常用选项：

| 选项 | 作用 |
|---|---|
| `--seed 数字` | 固定随机种子，身份分配可复现 |
| `--split Claude,GPT` | 让名字里含这些关键词的玩家分属不同阵营 |
| `--max-days 数字` | 最多打几天 |

在 `players.json` 某个座位里写 `"role": "女巫"` 可以固定他的身份。

## 第四步：出视频

```
python tts.py out/时间/log.json        # 配音（edge-tts，需要联网）
python render.py out/时间/log.json     # 生成 1080×1920 竖屏视频
```

`render.py --preview 60` 只渲染前 60 秒，`--snap 30,90` 只导出这几个时间点的截图，适合先看效果。

### 第一视角

```
python werewolf.py --export-pov out/时间/log.json --seat 8        # 8号的视角
python werewolf.py --export-pov out/时间/log.json --seat 女巫     # 女巫的视角
```

视角玩家只看到自己能知道的内容，出局后也一样（面杀规则）。导出的 `log_pov8.json` 同样可以配音、出视频。

### 精华版剪辑

整局太长时，可以写一份剪辑清单，只保留关键发言片段（逐字截取原话），加章节卡和花字：

```
python highlight.py out/时间/log.json 你的剪辑清单.json
python tts.py out/时间/highlight_pov8/log.json
python render.py out/时间/highlight_pov8/log.json
```

清单写法见 `highlight.py` 开头的说明，`examples/cut_fable_example.json` 是一份完整的例子（对应作者打过的一局，换了对局需要按新剧本重新写）。

### 封面和规则卡

```
python make_cover.py out/时间/log.json
```

生成 B站 横版封面（16:9、4:3）和片头规则卡。标题文字、主角座位号在脚本开头修改。

## 注意

- 调用模型会产生 API 费用，一整局 12 个模型可能要调用几百次，先用 `--mock` 和 `--check` 确认没问题再打。
- 配音用的是 edge-tts（微软在线语音），适合个人使用；商业用途请换成有正式授权的语音服务。
- 各家模型名称和商标归各自公司所有，本项目与这些公司没有关联。

AI Werewolf
Seat 12 large language models from different companies at one table and let them play a 12-player game of Werewolf (Seer / Witch / Hunter / Idiot, "kill-the-side" win condition), in the style of Chinese online Werewolf. A Python program acts as the judge: it deals roles, runs the day and night phases, keeps time, cuts off speakers, and counts votes, with no human input needed. After the game, you can voice the whole transcript, render it as a vertical video that looks like a mobile Werewolf app, and cut a highlight reel from any player's point of view.

Each AI only sees what its role is allowed to know (wolves know their teammates, the Seer knows their check results, and so on). Every model reasons, speaks, and votes on its own.
Each player gets 60 seconds at the start to plan. Every speech gets 90 seconds of thinking plus 90 seconds of talking; anyone who runs over is cut off by the judge. Daytime actions such as voting have a 60-second limit. At night, the wolves get 60 seconds to pick a target and the Seer and Witch get 30 seconds each. A timeout counts as abstaining or skipping the action.
Players who die on the first two nights, or are voted out during the day, get last words. Sheriff elections (including dropping out of the race), badge passing, the Hunter's shot, and the Idiot's reveal are all supported.
Language: the game prompts, the AI players' speech, and the voice-over are all in Chinese (Mandarin).

All speech is generated by the AI models and does not represent the views of the author or of any model provider.

Installation
Requires Python 3.10 or later.

pip install -r requirements.txt
Video rendering needs a Chinese font. Microsoft YaHei on Windows and PingFang on macOS are found automatically. On Linux, install Noto Sans CJK, or pass --font path/to/font to render.py.

Step 1: Try it for free
python werewolf.py --mock
--mock makes no API calls. It plays a full game with random speech so you can check that the setup works.

Step 2: Add API keys and configure the 12 seats
Copy keys.example.txt, rename the copy to keys.txt, and fill in your API keys. Never commit or share keys.txt.
players.json defines the 12 seats in order (seat 1 to 12): display name, model ID, API base URL, which key to use, and the text-to-speech voice. By default every seat uses the provider's official OpenAI-compatible endpoint.
Model IDs change as providers release new versions; check each provider's docs.
To swap a player, edit that line. Avatars are loaded from assets/avatars/<name>.png; if there is no file, a colored circle with the first letter is used instead.
Test every seat (each seat sends one short request, so it costs very little):
python werewolf.py --config players.json --check
To try it cheaply with a single key, players_test.json puts the same Zhipu model in all 12 seats.

Step 3: Play a game
python werewolf.py --config players.json
Results are saved in out/<timestamp>/: log.json (the full event log, used for voice-over and editing) and script.md (a readable transcript from the judge's point of view). The game auto-saves after every day, so an interrupted run keeps everything played so far.

Useful options:

Option	What it does
--seed N	Fix the random seed so role assignment is reproducible
--split Claude,GPT	Put players whose names contain these keywords on different teams
--max-days N	Stop after N days
To fix a player's role, add "role": "女巫" (the role name in Chinese) to that seat in players.json. Role names: 狼人 Werewolf, 村民 Villager, 预言家 Seer, 女巫 Witch, 猎人 Hunter, 白痴 Idiot.

Step 4: Make the video
python tts.py out/<timestamp>/log.json        # voice-over (edge-tts, needs internet)
python render.py out/<timestamp>/log.json     # 1080×1920 vertical video
render.py --preview 60 renders only the first 60 seconds, and --snap 30,90 saves still frames at those timestamps, which is handy for a quick check.

Point-of-view cut
python werewolf.py --export-pov out/<timestamp>/log.json --seat 8      # seat 8's view
python werewolf.py --export-pov out/<timestamp>/log.json --seat 女巫   # the Witch's view
The POV player only sees what they could know, even after being eliminated (as in a live, in-person game). The exported log_pov8.json can be voiced and rendered the same way.

Highlight reel
When a full game is too long, write a cut list that keeps only the key lines (quoted word for word) and adds chapter cards and on-screen captions:

python highlight.py out/<timestamp>/log.json your_cut_list.json
python tts.py out/<timestamp>/highlight_pov8/log.json
python render.py out/<timestamp>/highlight_pov8/log.json
The cut-list format is documented at the top of highlight.py. examples/cut_fable_example.json is a complete example; it matches one specific game the author played, so write a new one for your own games.

Cover and rules card
python make_cover.py out/<timestamp>/log.json
Generates landscape video covers (16:9 and 4:3) and a vertical rules card for the opening. Edit the title text and the featured seat at the top of the script.

Notes
Calling the models costs money. A full game with 12 models can make several hundred API calls, so run --mock and --check first.
The voice-over uses edge-tts (Microsoft's online voices) and is fine for personal use. For commercial use, switch to a properly licensed TTS service.
